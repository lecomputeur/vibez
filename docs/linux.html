VibeZ for Linux

A free Mistral Vibe desktop client for Linux, with native package formats and Linux-specific display controls.

AppImageDEBRPMPacmanFlatpak

Linux packages

VibeZ publishes several Linux package formats so users can install it in the way that best fits their distribution.

  • Debian, Ubuntu and Linux Mint: use the DEB package.
  • Fedora and RPM-based distributions: use the RPM package.
  • Arch Linux, Manjaro and EndeavourOS: use the Pacman package.
  • Portable use: choose the AppImage.
  • Flatpak: an x86_64 Flatpak bundle is also published.

x86_64 support

VibeZ provides AppImage, DEB, RPM, Pacman and Flatpak packages for conventional x86_64 Linux desktops.

Wayland and X11

Linux users get a display-backend setting with Automatic, Wayland and X11 choices. Automatic leaves selection to Electron so it can follow the active Linux session; users can force a backend when needed for compatibility or troubleshooting.

Desktop integration and screenshots

VibeZ adds a global screenshot shortcut, multi-monitor screenshot selection, system-tray access, XDG start-at-login integration, hardware acceleration settings, zoom controls and 34 VibeZ interface languages.

Quick install

The project also provides a one-line Linux installer that detects the distribution on x86_64 and verifies SHA-256 checksums when available. See the GitHub README for the current command and package details.

VibeZ is an independent open-source project and is not affiliated with or supported by Mistral AI.
