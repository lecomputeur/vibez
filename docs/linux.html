Native packages and AppImage require glibc 2.39 or newer. The DEB targets Ubuntu 24.04-class systems with WebKitGTK 4.1. AppImage does not guarantee compatibility with older distributions. Flatpak uses its declared GNOME runtime.

Install version 3.0.1

Close the old application completely. Open a terminal in your download directory and use the command for your package.

DEB

sudo apt install ./VibeZ-3.0.1-Linux-x64.deb

RPM

sudo dnf install ./VibeZ-3.0.1-Linux-x64.rpm

Arch / Pacman

sudo pacman -U ./VibeZ-3.0.1-Linux-x64.pkg.tar.zst

Flatpak

flatpak install --user ./VibeZ-3.0.1-Linux-x64.flatpak
flatpak run nl.lecomputeur.vibez3

AppImage

chmod +x ./VibeZ-3.0.1-Linux-x64.AppImage
./VibeZ-3.0.1-Linux-x64.AppImage

Start VibeZ 3 from the application menu. The native executable is vibez3; the DEB package name is vibe-z-3. Existing Electron and preview profiles are kept separate. Sign in once in the new application.

Rebuilt language handling. Corrected window and icon behavior.

Use System to follow your operating-system language or save another preference. Native language preparation, window resizing and repeated-start icon checks passed the release tests. Linux/Cinnamon testing by the maintainer confirmed the reported startup and icon fixes.

Screenshots rely on your desktop's capture/portal tools. Wayland and fractional scaling are not claimed fully tested. VibeZ checks published VibeZ 3 releases automatically by default and also offers a manual Check for updates action. Installing a direct-download update remains user-confirmed.
