Linux system requirements

Linux x86-64. Native packages and AppImage require glibc 2.39 or newer and WebKitGTK 4.1. The DEB targets Ubuntu 24.04-class systems and has been tested on Linux Mint 22.3/X11. AppImage does not remove these requirements. Flatpak uses its declared GNOME runtime and requires a working Flatpak installation.

How to install the Linux desktop app

The DEB, RPM and Arch installers close the running installed version automatically. Open a terminal in your download directory and use the command for your package.

DEB

sudo apt install ./VibeZ-3.0.9-Linux-x64.deb

RPM

sudo dnf install ./VibeZ-3.0.9-Linux-x64.rpm

Arch / Pacman

sudo pacman -U ./VibeZ-3.0.9-Linux-x64.pkg.tar.zst

Flatpak

flatpak install --user ./VibeZ-3.0.9-Linux-x64.flatpak
flatpak run nl.lecomputeur.vibez3

AppImage

chmod +x ./VibeZ-3.0.9-Linux-x64.AppImage
./VibeZ-3.0.9-Linux-x64.AppImage

Linux download questions

Which package should I use on Linux Mint or Ubuntu?

The DEB targets Ubuntu 24.04-class systems and has been tested on Linux Mint 22.3/X11. Download the DEB above and install it with the apt command in the installation guide. For another distribution, choose a package format it supports and check the system requirements.

Will the AppImage run on an older Linux distribution?

The AppImage still requires glibc 2.39 or newer and WebKitGTK 4.1. If your native libraries are too old, consider the Flatpak package and check that your distribution can run its declared GNOME runtime.

Is VibeZ free, and does it run AI models locally?

VibeZ is a free, MIT-licensed client for Mistral's hosted web service. It needs internet access. Mistral controls account requirements and any paid plans; installing VibeZ does not install a local AI model.

Where can I report a Linux problem?

Use the VibeZ issue tracker and include your distribution, VibeZ version and package format. For another computer, see the Mac desktop app or Windows desktop app.
