Install version 3.0.3

Close the old application completely. Open a terminal in your download directory and use the command for your package.

DEB

sudo apt install ./VibeZ-3.0.3-Linux-x64.deb

RPM

sudo dnf install ./VibeZ-3.0.3-Linux-x64.rpm

Arch / Pacman

sudo pacman -U ./VibeZ-3.0.3-Linux-x64.pkg.tar.zst

Flatpak

flatpak install --user ./VibeZ-3.0.3-Linux-x64.flatpak
flatpak run nl.lecomputeur.vibez3

AppImage

chmod +x ./VibeZ-3.0.3-Linux-x64.AppImage
./VibeZ-3.0.3-Linux-x64.AppImage

Start VibeZ 3 from the application menu. The native executable is vibez3; the DEB package name is vibe-z-3. Existing Electron and preview profiles are kept separate. Sign in once in the new application.

Rewritten app. Redesigned language handling.

VibeZ 3's desktop application was rebuilt from the ground up around Rust + Tauri and WebKitGTK. The language flow was redesigned to solve the earlier system-language, startup and switching issues rather than carrying the old behavior forward. Use System to follow your operating-system UI language or save another preference; startup locale preparation and live switching are ordered so stale operations cannot revert the latest choice. Native language preparation, window resizing and repeated-start icon checks passed the release tests. Linux/Cinnamon testing by the maintainer confirmed the reported startup and icon fixes.

Screenshots rely on your desktop's capture/portal tools. Wayland and fractional scaling are not claimed fully tested. VibeZ checks published VibeZ 3 releases automatically by default and also offers a manual Check for updates action. Installing a direct-download update remains user-confirmed.

Compare downloads with SHA256SUMS. All release files and notes.

Updates from inside VibeZ

VibeZ checks for published updates automatically at startup. Download the matching package inside VibeZ, with progress, cancellation and SHA-256 verification, then explicitly open the installer. VibeZ does not install silently or force a restart. Microsoft Store installations use Store delivery.

Version 3.0.3 also fixes the macOS toolbar being partly hidden behind the titlebar. The Store version follows Microsoft certification and may become available later than the direct downloads.
