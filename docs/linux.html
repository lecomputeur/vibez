Upgrade from VibeZ 3

When the migration update appears in VibeZ 3, choose the same package format you already use. The AppImage replaces the existing file. For DEB, RPM or Arch, confirm the package manager's replacement of VibeZ 3. The new application uses its own profile. Sign in to the same Mistral account to access your existing conversations.

If you installed the VibeZ 3 Flatpak from GitHub, install the VibeZ 4 Flatpak above, then remove VibeZ 3 from your software manager. Keep its data if prompted.

Linux system requirements

Linux x86-64. Native packages and AppImage require glibc 2.39 or newer and WebKitGTK 4.1. The DEB targets Ubuntu 24.04-class systems and has been tested on Linux Mint 22.3/X11. AppImage does not remove these requirements. Flatpak uses its declared GNOME runtime and requires a working Flatpak installation.

Moving from test.2 or test.3 to VibeZ 3.2.0

Uninstall the test version first, then install the regular VibeZ 3.2.0 package. Keep saved data from ordinary test.2. The separate Canvas Test app is no longer needed and can be removed. Save unfinished drafts and close VibeZ completely before removing the test app.

The ordinary test.2 build can be treated as newer than 3.2.0. Its graphical installer may report “A newer version is already installed”, and the app may not offer the stable release as an update.

Test.2 installed from a DEB

Remove the test application in Software Manager, or run:

sudo apt remove vibe-z-3

VibeZ Canvas Test (test.3) installed from a DEB

sudo apt remove vibe-z-canvas-test

VibeZ Canvas Test (test.3) installed as a user Flatpak

flatpak uninstall --user nl.lecomputeur.vibez3.CanvasTest

Use --system instead of --user for a system-wide installation. Keeping Canvas Test data is optional. Add --delete-data if you also want to remove its saved test data.

For other test packages, remove the test app through your distribution’s software manager. The native DEB/RPM package is vibe-z-3 for ordinary test.2 or vibe-z-canvas-test for the separate Canvas Test. Keep the saved data when removing ordinary test.2.

After removal, install the regular 3.2.0 package using the instructions below. Ordinary test.2 settings and saved data remain available to the regular app.

How to install the Linux desktop app

The DEB, RPM and Arch installers close the running installed version automatically. Open a terminal in your download directory and use the command for your package.

DEB

sudo apt install ./VibeZ-3.2.0-Linux-x64.deb

RPM

sudo dnf install ./VibeZ-3.2.0-Linux-x64.rpm

Arch / Pacman

sudo pacman -U ./VibeZ-3.2.0-Linux-x64.pkg.tar.zst

Flatpak

flatpak install --user ./VibeZ-3.2.0-Linux-x64.flatpak
flatpak run nl.lecomputeur.vibez3

AppImage

chmod +x ./VibeZ-3.2.0-Linux-x64.AppImage
./VibeZ-3.2.0-Linux-x64.AppImage

Start VibeZ 3 from the application menu. The native executable is vibez3; the DEB package name is vibe-z-3. Upgrades within VibeZ 3 retain the existing settings and profile. Older Electron and preview profiles remain separate.

A dedicated Linux client for Mistral Vibe

Keep the Mistral website in its own desktop window, with Back, Forward, reload, zoom, screenshots and language selection. VibeZ uses Rust + Tauri and WebKitGTK, with 34 interface-language bundles. Choose System to follow your desktop language or save another preference; website translations remain controlled by Mistral.

Linux desktop-area screenshot selection requires X11. Wayland and fractional scaling have not been fully tested. VibeZ is an independent open-source client and is not affiliated with or endorsed by Mistral AI.

Linux download questions

Which package should I use on Linux Mint or Ubuntu?

The DEB targets Ubuntu 24.04-class systems and has been tested on Linux Mint 22.3/X11. Download the DEB above and install it with the apt command in the installation guide. For another distribution, choose a package format it supports and check the system requirements.

Will the AppImage run on an older Linux distribution?

The AppImage still requires glibc 2.39 or newer and WebKitGTK 4.1. If your native libraries are too old, consider the Flatpak package and check that your distribution can run its declared GNOME runtime.

Is VibeZ free, and does it run AI models locally?

VibeZ is a free, MIT-licensed client for Mistral's hosted web service. It needs internet access. Mistral controls account requirements and any paid plans; installing VibeZ does not install a local AI model.

Where can I report a Linux problem?

Use the VibeZ issue tracker and include your distribution, VibeZ version and package format. On Windows or Mac, use the official Vibe Desktop.
