How to install VibeZ on your Mac

Choose the package matching your Mac. Open the DMG, drag VibeZ 3 into Applications and launch it from there. For ZIP, extract the application and move it into Applications.

Upgrading an existing VibeZ 3 installation retains its settings and profile. Older Electron and preview profiles stay separate; sign in again when moving from those editions. Screenshots use macOS capture tools; grant Screen Recording permission when macOS requests it. Paste with ⌘V.

VibeZ uses Rust + Tauri and Apple WKWebView to open the Mistral website in a dedicated Mac window. Back, Forward, reload, zoom, screenshot tools and 34 interface languages are built in. Choose System to follow your macOS language or save another preference; website translations remain controlled by Mistral.

Microphone/camera access and global screenshot shortcuts are not enabled in version 3.0.9. No Electron runtime is bundled with the application.

Mac download questions

Is there a Mistral Vibe desktop app for macOS?

VibeZ is an independent, free desktop client that opens the Mistral website in its own Mac window. It includes screenshots, zoom and language selection. It is not affiliated with or endorsed by Mistral AI.

Should I choose Apple Silicon or Intel?

Open the Apple menu and choose About This Mac. If it shows an Apple chip, choose the Apple Silicon download. If it shows an Intel processor, choose the Intel download. Both require macOS 14 or later.

Are the Mac downloads signed and notarized?

Yes. Both Mac architectures passed Developer ID signing, Apple notarization and stapled-ticket validation in the verified 3.0.9 build. Download the DMG or ZIP from the links above and compare it with the release's SHA256SUMS file.

Does VibeZ include a Mistral subscription or a local AI model?

VibeZ itself is free and open source. It uses Mistral's hosted service and needs internet access. Mistral controls account requirements and paid plans; VibeZ does not install a local AI model. For other systems, see the Linux desktop app or Windows desktop app.
