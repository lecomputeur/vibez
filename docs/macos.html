Requires macOS 14 or newer. Both architectures passed Developer ID signing, Apple notarization and stapled-ticket validation.

Install and start

Choose the package matching your Mac. Open the DMG, drag VibeZ 3 into Applications and launch it from there. For ZIP, extract the application and move it into Applications.

The new app uses a separate profile; sign in once. Existing Electron and preview profiles are not silently removed or imported. Screenshots use macOS capture tools; grant Screen Recording permission when macOS requests it. Paste with ⌘V.

System language, explicit language selection and native cookie preparation are handled by the rebuilt language module. WKWebView history, language, popup and window probes passed for both architectures. Automated probes are not a substitute for testing every live sign-in provider.

Updates are installed manually. Microphone/camera and global screenshot shortcuts are not enabled in version 3.0.0. No Electron runtime is bundled with the new application.
