Install and start

Choose the package matching your Mac. Open the DMG, drag VibeZ 3 into Applications and launch it from there. For ZIP, extract the application and move it into Applications.

The new app uses a separate profile; sign in once. Existing Electron and preview profiles are not silently removed or imported. Screenshots use macOS capture tools; grant Screen Recording permission when macOS requests it. Paste with ⌘V.

VibeZ 3 was rewritten from the ground up around Rust + Tauri and WKWebView. Its language system was redesigned specifically to address the earlier system-language, startup and switching issues: System resolves the macOS UI language, explicit choices are stored and restored, and supported website locale preparation is ordered so stale operations cannot undo newer choices. WKWebView history, language, popup and window probes passed for both architectures. Automated probes are not a substitute for testing every live sign-in provider.

VibeZ checks published VibeZ 3 releases automatically by default and also offers a manual Check for updates action; installation remains user-confirmed. Microphone/camera and global screenshot shortcuts are not enabled in version 3.0.4. No Electron runtime is bundled with the new application.

Updates from inside VibeZ

VibeZ checks for published updates automatically at startup. Download the matching package inside VibeZ, with progress, cancellation and SHA-256 verification, then explicitly open the installer. VibeZ does not install silently or force a restart. Microsoft Store installations use Store delivery.
