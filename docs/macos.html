VibeZ for macOS

A free Mistral Vibe desktop client for Mac, available for Apple silicon and Intel.

Mac with Apple silicon (M1 or newer)Mac with Intel processor

Which Mac download should I choose?

  • Mac with Apple silicon: choose macOS-arm64.dmg for an M1 chip or newer.
  • Mac with Intel processor: choose macOS-x64.dmg.
  • ZIP packages are also available for both architectures.

What does VibeZ add on macOS?

VibeZ provides a dedicated desktop window for the official Mistral Vibe service together with screenshot tools, multi-monitor capture, menu-bar access, start-at-login support, platform-aware keyboard labels and 34 VibeZ interface languages.

Developer ID signing and notarization

VibeZ 2 macOS packages are signed with an Apple Developer ID certificate and notarized by Apple. GitHub Actions verifies the signature, Gatekeeper acceptance and notarization before publication. Release downloads also include SHA-256 checksums.

Screenshot permission on macOS

macOS protects screen capture at operating-system level. The first time you use VibeZ screenshots, you may need to allow VibeZ under System Settings → Privacy & Security → Screen & System Audio Recording or Screen Recording, depending on your macOS version.

Updates on Mac

Starting with VibeZ 2.0.1, signed installations can download verified updates in the app. VibeZ selects the correct Intel or Apple silicon package and offers Restart & update or Later.
