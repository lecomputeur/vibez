Which Windows installer should I download?

For the simplest trusted installation, use the Microsoft Store after Microsoft has published the listing. You can also download the Windows x64 installer directly from GitHub.

  • Microsoft Store: the recommended route once certification and publication are complete.
  • Direct download: use the file ending in Windows-x64.exe.

What does VibeZ add on Windows?

VibeZ opens the official Mistral Vibe service in a dedicated Electron desktop window and adds a global screenshot shortcut, multi-monitor screenshot selection, system-tray access, start-at-login support, configurable desktop settings and a VibeZ interface available in 34 languages.

Microsoft Store

VibeZ has been submitted to the Microsoft Store. Store-distributed apps are validated and signed by Microsoft. The Microsoft Store page will become available after Microsoft approves and publishes the listing; until then, use the direct GitHub installer.

Windows SmartScreen and direct GitHub downloads

The installer downloaded directly from GitHub is unsigned. Windows SmartScreen may therefore show Windows protected your PC or Unknown publisher the first time you run it. Only continue when you downloaded VibeZ from the official GitHub repository and verify the supplied SHA-256 checksum. See the Code signing policy for the current platform policy.

Updates on Windows

Packaged Windows versions can check GitHub Releases for VibeZ updates. When supported, VibeZ downloads the update and asks before restarting to install it.

VibeZ is an independent open-source project and is not affiliated with or supported by Mistral AI.
