Windows system requirements

A Windows x64 computer, Microsoft Edge WebView2 Runtime and internet access for Mistral's web service. These downloads are x64 builds; separate Windows ARM64 and 32-bit builds are not provided.

The direct EXE/MSI installers are unsigned. Windows may show a reputation warning; download only from the project release and verify the checksum. Do not disable Windows security protections.

How to install VibeZ on Windows

  1. Download the EXE or MSI above and check it against the release's SHA256SUMS file.
  2. Run your chosen installer and follow its setup steps.
  3. Open VibeZ 3 from the Start menu.

Upgrading an existing VibeZ 3 installation retains its settings and profile. Older Electron and preview profiles remain separate; sign in again when moving from those editions.

VibeZ uses Microsoft Edge WebView2 Runtime to display the Mistral website. If the runtime is missing, use Microsoft's official WebView2 Runtime download. Installing the Edge browser alone is not a substitute for the runtime.

A dedicated Windows client for Mistral Vibe

Open Mistral in its own desktop window, with Back, Forward, reload, zoom, screenshot tools and 34 interface languages. VibeZ uses Rust + Tauri and Microsoft WebView2, without bundling an Electron runtime.

Choose System to follow your Windows display language, or save another interface language. Website translations remain controlled by Mistral. Microphone/camera access and global screenshot shortcuts are not enabled in version 3.0.9.

Windows download questions

Is there a Mistral Vibe desktop app for Windows?

VibeZ is an independent, free desktop client that opens the Mistral website in its own Windows window. It adds screenshots, zoom and interface-language selection. It is not affiliated with or endorsed by Mistral AI.

Should I download the EXE or MSI?

Choose the Setup EXE for a guided installation. Choose the MSI if you need a Windows Installer package, for example for a deployment process that accepts MSI files. Both are x64 installers for the same VibeZ release; you only need one.

Do I need Microsoft Edge WebView2?

Yes. VibeZ requires the WebView2 Runtime to display the Mistral website. It is a separate component from the Edge browser. See Microsoft's WebView2 Runtime guidance if it is missing.

Is VibeZ free, and does it run AI models locally?

VibeZ itself is free and open source. It uses Mistral's hosted service and needs internet access. Mistral controls account requirements and paid plans; VibeZ does not install a local AI model. For other systems, see the Mac desktop app or Linux desktop app.
