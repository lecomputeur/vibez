Installation and migration

Run one installer and open VibeZ 3. Version 3's direct installation uses a separate profile; sign in once in the new app. Existing Electron data is not silently deleted or imported.

VibeZ 3's desktop application was rewritten from the ground up around Rust + Tauri and Microsoft WebView2. The language system was redesigned with it to fix the earlier system-language, startup and switching behavior: System follows the Windows display language, explicit choices are stored and restored, and supported Mistral website preferences are prepared and applied in order. Real WebView2 history, cookie preparation and popup-isolation tests passed in the all-format build.

Direct installations check automatically for published VibeZ 3 updates by default and also provide a manual Check for updates action. Microsoft Store installations use Store update delivery. Microphone/camera access and global screenshot shortcuts are not enabled in version 3.0.5.

Microsoft Store is a separate delivery channel

The version 3.0.5.0 Store MSIX is built for Partner Center submission. It is not a normal unsigned sideload installer and its presence does not mean Microsoft has approved or published version 3.

The existing VibeZ Desktop Store listing is updated separately. Use the EXE or MSI above for the GitHub version 3 release.

Updates from inside VibeZ

VibeZ checks for published updates automatically at startup. Download the matching package inside VibeZ, with progress, cancellation and SHA-256 verification, then open the installer. VibeZ 3.0.5 closes automatically when it hands off the installation. AppImage updates replace the original file and start the new version after the old instance exits.
