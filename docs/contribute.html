VibeZ · Winding down

Report a Linux problem

Mistral released the official Vibe Desktop for macOS and Windows, so VibeZ is winding down. Until the official Linux app is available, VibeZ keeps supporting Linux.

No new features are planned. Reports about VibeZ on Linux are still welcome and get fixed where possible. On Windows or Mac, please use the official app.

Report a Linux problem Thank you

A useful report can be short

Search the existing issues first, then report one problem at a time. English makes reports easier to share, but your own language is welcome.

  • Version: the full VibeZ version shown in the app.
  • System: distribution, version, desktop and processor.
  • Package: DEB, RPM, Flatpak, AppImage or Arch.
  • Result: what you tried, what you expected and what happened.

Remove passwords, access tokens and private file contents before posting.

The code stays open

The source of VibeZ V4 is in v4/ and VibeZ 3 is in desktop/, under the MIT license. You are welcome to fork it, learn from it or build on it.
