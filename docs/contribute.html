A useful test report can be short

Use a package from the published releases and test with copies of files in a temporary folder. V4 Beta is a separate app and does not replace stable VibeZ 3.0.9.

  • Version: the full VibeZ version shown in the app.
  • System: operating system, version and processor.
  • Package: DEB, RPM, Flatpak, AppImage, Arch, EXE, MSI or DMG.
  • Result: what you tried, what you expected and what happened. Say whether you used Work or Code.

Good checks include connecting local folders, switching projects, reading files, approving or refusing edits and downloading generated files. Add screenshots or clear steps when helpful. Remove passwords, access tokens and private file contents.

Reply to the original report with follow-up results. If a separate bug appears, open a separate issue. A fix is only ready for you to confirm when its issue names a published version containing it.

See what happens next

Release milestones group the work planned for a version. Issue labels show the next step: triage → in progress → ready to test → verified. The issue records which release and systems were checked.

View release progressFollow V4 releases

One announcement gathers each public release. Your original issue remains the place for its detailed follow-up. You can subscribe to the discussion or use GitHub's Watch settings to choose your notifications.

Code and documentation

Check the version before starting. The public desktop source is VibeZ 3. The V4 implementation is maintained separately and is not in GitHub's automatic Alpha source archives.

For public V3 code, the website or documentation, fork the repository and open a focused pull request. Link an issue and explain how you checked the change. For V4 code, discuss the change in an issue first so the maintainer can clarify the correct source and review route. An issue does not automatically grant access to private code.

Wording suggestions can be sent as plain text. Say whether the text belongs to VibeZ or Mistral's website, because Mistral controls its own translations.
