Not a port.
A ground-up rewrite.

VibeZ 3 was rebuilt from the ground up around Rust + Tauri rather than extending the old Electron application. The native application architecture, window integration, settings flow, navigation layer and platform packaging are new. It uses WebKitGTK on Linux, Microsoft WebView2 on Windows and Apple WKWebView on macOS instead of shipping its own Electron runtime. The familiar navigation, language, zoom and screenshot controls remain.

The native application layer is written in Rust; the bundled controls and the Mistral website still use web technologies. This is an architectural upgrade, not a claim that the website has been rewritten or that every workload is faster.

The language issue was redesigned, not patched.

The earlier language-selection and startup behavior was treated as an architectural problem. VibeZ 3 rebuilds system-language detection, saved preferences, startup locale preparation and live language switching as one ordered flow.

System really means system

Follow your operating-system language, or save a specific language. Your location does not override your choice.

Switch without going backwards

Versioned language changes prevent older responses and stale settings windows from reverting your newer preference.

Prepared before the page opens

Browser language preparation, bounded retries and recovered-warning cleanup address the reported startup problem.

Native language preparation is tested on WebKitGTK, WebView2 and WKWebView. The maintainer also tested the reported switching and startup issues on Linux/Cinnamon. Website translations remain controlled by Mistral; unsupported website languages fall back to English.

Built. Tested. Open to inspection.

The verified 3.0.9 build passed all nine required platform/security jobs, producing all twelve packages from one frozen commit, including signed/notarized Intel and Apple Silicon Mac downloads. Both native architectures and macOS 14 deployment requirements were verified. See the release proof; the release asset list records download availability.

Automated native probes do not test every live sign-in provider or desktop configuration. Automatic update checks are enabled by default for direct installs; installation remains user-confirmed. Microsoft Store installations use Store delivery. Microphone/camera and global screenshot shortcuts are not enabled in version 3.0.9. Existing Electron and preview profiles are not silently copied or removed.

Screenshots in VibeZ 3

Capture the visible page, the full loaded page or a desktop selection. Copy the image, save a PNG or paste it into a Chat or Work draft without sending a message. In Code, save the screenshot as a file and attach it separately.

Full-page capture includes loaded content, not unloaded history. Linux desktop-area selection requires X11; macOS may ask for Screen Recording permission.

Updates from inside VibeZ

VibeZ checks for published updates automatically at startup. Download the matching package inside VibeZ, with progress, cancellation and SHA-256 verification, then open the installer. VibeZ 3.0.9 closes automatically when it hands off the installation. AppImage updates replace the original file and start the new version after the old instance exits. Microsoft Store installations use Store delivery.

VibeZ 3.0.9 improves Linux embedded Canvas/chart and verification routing. Testers confirmed working previews and a completed Cloudflare sign-in in the test Flatpak. The original heavy conversation still reaches 100% CPU at idle; no complete performance fix is claimed.
