VibeZ · Winding down

Mistral Vibe has
its own desktop app

On 17 November 2026 Mistral released Vibe Desktop for macOS and Windows: Work, local folders and coding in one official app.

It has been quite an undertaking, but our beloved Mistral Vibe finally has its long-awaited desktop client. VibeZ was always a stand-in for that app, so VibeZ is now winding down.

Get the official Vibe Desktop VibeZ for Linux

VibeZ is an independent open-source client. It is not affiliated with, endorsed by or supported by Mistral AI. Mistral's release notes

What happens now

Windows and macOS

Use the official Vibe Desktop. VibeZ for Windows and Mac is no longer developed and receives no further updates. The existing downloads stay available in the release archive.

Linux

Mistral says Linux support is coming soon. Until the official Linux app is available, VibeZ keeps supporting Linux: VibeZ 3.2.0 and the V4 Beta, with fixes for reported problems.

The code

The source stays on GitHub under the MIT license. Development is winding down; no new features are planned.

V4 Beta · Linux

VibeZ V4 Beta for Linux

V4 lets Mistral Work and Code use local folders you choose, with every file change shown for your approval. It installs next to VibeZ 3 with its own profile and settings.

VibeZ 4.0.0 is available for Linux. VibeZ 4 is final: Mistral Work and Code with your own folders on Linux, every change shown for your approval. It also works on systems such as NixOS and uses your desktop's own file dialog.
