VibeZ 3

Same Vibe. Rebuilt in Rust.

VibeZ is a free, open-source desktop app for Mistral Vibe on Windows, macOS and Linux. VibeZ 3 was rewritten from the ground up around Rust + Tauri, with a redesigned language system and native desktop integration.

Not a port.
A ground-up rewrite.

VibeZ 3 was rebuilt from the ground up around Rust + Tauri rather than extending the old Electron application. The native application architecture, window integration, settings flow, navigation layer and platform packaging are new. It uses WebKitGTK on Linux, Microsoft WebView2 on Windows and Apple WKWebView on macOS instead of shipping its own Electron runtime. The familiar navigation, language, zoom and screenshot controls remain.

The native application layer is written in Rust; the bundled controls and the Mistral website still use web technologies. This is an architectural upgrade, not a claim that the website has been rewritten or that every workload is faster.

The language issue was redesigned, not patched.

The earlier language-selection and startup behavior was treated as an architectural problem. VibeZ 3 rebuilds system-language detection, saved preferences, startup locale preparation and live language switching as one ordered flow.

System really means system

Follow your operating-system language, or save a specific language. Your location does not override your choice.

Switch without going backwards

Versioned language changes prevent older responses and stale settings windows from reverting your newer preference.

Prepared before the page opens

Browser language preparation, bounded retries and recovered-warning cleanup address the reported startup problem.

Native language preparation is tested on WebKitGTK, WebView2 and WKWebView. The maintainer also tested the reported switching and startup issues on Linux/Cinnamon. Website translations remain controlled by Mistral; unsupported website languages fall back to English.

Built. Tested. Open to inspection.

The all-format workflow passed its native tests, dependency-security check, packaging checks and Apple signing/notarization gates. Inspect the verified build and read the release notes.

Automated native probes do not test every live sign-in provider or desktop configuration. Automatic update checks are enabled by default for direct installs; installation remains user-confirmed. Microsoft Store installations use Store delivery. Microphone/camera and global screenshot shortcuts are not enabled in version 3.0.5. Existing Electron and preview profiles are not silently copied or removed.

Screenshots in VibeZ 3

Visible page, Full page and Selection remain in a compact menu. Paste directly into Chat and Work drafts without sending a message. In Code, choose Screenshot as file, save as PNG and share the file separately. The short Code explanation and conditional sign-in notice are translated into all 34 interface languages. Copying and saving are available without signing in.

A compact menu with Visible page, Full page and Selection, translated into all 34 interface languages. Copy, save a PNG or paste directly into your Chat or Work draft without sending it. The menu opens on the same monitor as VibeZ.

Full page captures loaded content, not unloaded history. Linux desktop selection requires X11. macOS desktop capture may require Screen Recording permission. The Microsoft Store release follows its separate certification process.

Updates from inside VibeZ

VibeZ checks for published updates automatically at startup. Download the matching package inside VibeZ, with progress, cancellation and SHA-256 verification, then open the installer. VibeZ 3.0.5 closes automatically when it hands off the installation. AppImage updates replace the original file and start the new version after the old instance exits. Microsoft Store installations use Store delivery.
