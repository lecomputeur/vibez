Free downloads

VibeZ is an independent project and is not affiliated with or supported by Mistral AI. A Mistral account may be required to use Vibe.

Common questions

Is VibeZ the official Mistral Vibe desktop app?

No. VibeZ is an independent open-source desktop client that opens the official Mistral Vibe service and adds desktop-focused features.

Does VibeZ work on Windows and Mac as well as Linux?

Yes. VibeZ provides Windows x64, macOS builds for Apple Silicon and Intel, and multiple Linux package formats for x86_64.

Where should I download VibeZ?

On Windows, use the Microsoft Store. For macOS, Linux and direct Windows downloads, use the official GitHub Releases page. Every public release includes SHA-256 checksums.
