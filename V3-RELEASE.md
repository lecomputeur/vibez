# VibeZ 3.0.4 — Small fixes and stability improvements

Small fixes and stability improvements for Linux, Windows and macOS.

All twelve download formats are available: Linux AppImage, DEB, RPM, Arch/Pacman and Flatpak; Windows EXE, MSI and Store submission MSIX; and macOS DMG and ZIP for Intel and Apple Silicon. macOS packages are signed, notarized and stapled. Downloads include SHA-256 checksums.

Quit VibeZ completely before updating. Existing VibeZ 3 profiles are retained. Direct installations can download the update inside VibeZ and explicitly open the installer; Microsoft Store installations use Store delivery.

Native Linux packages require glibc 2.39+ and WebKitGTK 4.1; Linux desktop selection requires X11. macOS requires version 14 or later, and Windows requires WebView2.

[The verified all-platform build](https://github.com/lecomputeur/vibez/actions/runs/38053433480) passed all nine platform, dependency and packaging gates. The Store MSIX is version 3.0.4.0; Microsoft Store submission and certification remain separate from this GitHub release.
