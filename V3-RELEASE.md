# VibeZ 3.0.7 candidate — Linux rich-chat rendering and resize improvements

This is a release candidate under preparation, not a published or fully validated release. The existing 3.0.6 downloads and their proof records remain unchanged.

On Linux, recognized long assistant replies can skip offscreen rendering while retaining measured heights. Height refreshes run in bounded batches so scrolling and window resizing can continue. Streaming replies, native Find and page screenshots temporarily expand the relevant content. Unknown conversation markup is left untouched. Normal GTK container allocation avoids the transient 1×1 webview size observed in the earlier resize path.

The change targets Linux AppImage, DEB, RPM, Arch/Pacman and Flatpak builds. It preserves the existing code-header appearance, ordinary Mistral startup, `nl.lecomputeur.vibez3` identity, `vibez3` executable, profile locations and published-release update flow. It does not replace the normal client with the synthetic test chat. Windows and macOS rendering behavior stays unchanged; all platforms use **VibeZ V3.0.7** in the window title.

The preceding isolated Mint experiment used 40 synthetic long assistant replies containing tables and code blocks. In its automatic 30-second wheel comparison, measured WebKit CPU averaged 118.0% without the rendering improvement and 28.7% with it; 100% means one logical CPU. Resize evidence showed the first fresh nonblank capture at 111 ms and usable wheel input at 69 ms in that experiment. These are measurements of the offline experimental build, not certification of the 3.0.7 packages or a guarantee for every live conversation, driver or machine.

Before publication, the candidate must pass the frozen-source [validation workflow](.github/workflows/v3.0.7-validation.yml), including dependency advisories, frontend/Rust tests, rich-chat streaming/search/resize regressions, installer/update regression tests, native screenshot/paste/window tests, all twelve required packages and macOS signing/notarization. Fresh 3.0.7 source and checksum evidence is required. The existing 3.0.6 proof must not be relabeled or reused as candidate proof. Anonymous hosted-Mistral checks must distinguish signed-out page compatibility from actual conversation-selector coverage; unavailable or unrecognized conversation markup must be reported explicitly.

Native Linux packages require glibc 2.39+ and WebKitGTK 4.1; Linux desktop screenshot selection requires X11. macOS requires version 14 or later, and Windows requires WebView2. Microsoft Store package creation, submission and certification remain separate. The Windows package derives Store version `3.0.7.0` from the same app version.
